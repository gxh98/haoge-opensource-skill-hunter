# 昊哥-开源skill技能猎手

**找开源，先验活。** 需求先行的 GitHub 开源项目选型技能——先锚定需求，再三层品控验货，最后给出猎手洞见。

> 本技能中文名：**昊哥-开源skill技能猎手**。GitHub 仓库名 `haoge-opensource-skill-hunter` 仅为平台技术标识（GitHub 不支持中文仓库名），转载、收录、引用请以中文名为准。

## 它解决什么问题

- **星数会骗人**：星数最高的项目可能早停更了，装上就是坑。技能把"先验存活"放在评分前面——否决项扫描先于一切打分。
- **没想清需求就开筛**：选型失败多数不是筛得不好，是没想清要什么。技能第一步强制问清 5-7 个结构化问题，需求锚不确认不动手。
- **选完不知道为什么**：交付的不只是"选 A"，还有猎手洞见——作者在利益冲突时刻的行为记录、赛道当下的生态时机、与需求锚的化学反应。

## 主要功能

- **第一步 · 锚定需求**：必问 4 问（场景/环境/第一要求/红线）+ 选问 3 问（使用者/参照物/死线），每问标注"这问决定什么"。
- **第二步 · 狩猎**：候选发现（交叉关键词搜索）+ 三层品控——L1 否决项（停更/删库自宣/越线功能）、L2 硬门槛（平台匹配/活跃度）、L3 评分排序（权重随需求锚动态调整）。
- **第三步 · 猎手洞见**：作者行为记录、生态时机判断、与需求锚的化学反应——基于实际查证，不说玄学。
- **第四步 · 交付四件套**：死亡名单表、评分表、首选推荐（含洞见段）、落地三步+风险一句话。

内置完整示范案例：微信聊天记录导出工具 8 选 1（8 查 7 死，星数最高的赛道头部全灭）。

## 安装方法

这是一个 AI Agent 技能（遵循 SKILL.md 规范），不是传统软件：

```bash
git clone https://github.com/gxh98/haoge-opensource-skill-hunter.git
```

- **Claude Code**：把 `SKILL.md` 放入 `.claude/skills/opensource-picker/SKILL.md`
- **其他支持自定义技能/提示词的 Agent 平台**：把 `SKILL.md` 全文粘贴进系统提示词或技能库

## 使用方法

对你的 AI Agent 说一句：

```text
帮我找一个微信聊天记录导出的开源工具
```

技能会先问你 5-7 个问题锚定需求（场景/环境/第一要求/红线），确认需求锚后开始狩猎，最后给出首选推荐和猎手洞见。需求锚没确认前，它拒绝直接甩清单——这是特性，不是 bug。

## 输入输出示例

**输入**

```text
帮我找一个微信聊天记录导出的开源工具
```

**输出（节选）**

```text
第一步 · 锚定需求
- 你拿它解决什么问题？（例：导出聊天记录喂AI）
- 跑在什么环境和平台？（Windows + 微信4.x）
- 第一要求？稳定安全可靠 / 功能最全 / 最新最快 / 完全免费
- 红线？绝对不能踩什么？（如：账号安全）

第二步 · 狩猎（8 个候选 → 7 个被否决）
死亡名单：星数第一的 4.2 万★项目已代码清空自宣停更……

第三步 · 猎手洞见
微信官方对该赛道系统性清剿，此刻"活着且活跃"
本身就是最稀缺的指标——这不是评分表能算出来的。
```

## 暂不支持

- 闭源商业软件的选型——只管开源项目
- 不问需求直接甩清单——需求锚未确认，技能拒绝动手
- 对"星数=质量"的默认信任——星数只是评分表里的 15 分
